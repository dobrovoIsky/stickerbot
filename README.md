# 🎨 Sticker Factory Telegram Bot

Повнофункціональний Telegram-бот на **Python 3 (aiogram 3)** для автоматичного створення стікерів із фотографій, видалення фону (rembg), додавання білої обводки, накладання тексту та збирання персональних стікерпаків користувачів із гнучкою системою монетизації (перевірка підписок на канали).

---

## 🚀 Основні можливості

1. **Обробка фотографій у стікери:**
   - Автоматичне видалення фону за допомогою AI (`rembg`).
   - Накладання фірмової білої контурної обводки.
   - Оптимізація та масштабування під стандарти Telegram (512x512).
   - Експорт у формат **WebP**.
   - Додавання мем-тексту з чорною обводкою та динамічним розміром шрифту.
   - Інтерактивні кнопки: можливість увімкнути/вимкнути обводку або залишити оригінальний фон.

2. **Персональні стікерпаки:**
   - Автоматичне створення власного стікерпаку користувача (`createNewStickerSet`).
   - Додавання кожного нового стікера до набору (`addStickerToSet`).
   - Посилання виду `t.me/addstickers/{pack_name}` для поширення та встановлення друзями.

3. **Гнучка система перевірки підписок на канали:**
   - Збереження каналів у базі даних (без потреби змінювати код).
   - Підтримка власних та рекламних каналів.
   - Увімкнення/вимкнення перевірки в один клік через адмін-панель.
   - Кешування результатів перевірки для запобігання лімітам Telegram Bot API.
   - Захист: динамічна перевірка перед генерацією кожного стікера.

4. **Адмін-панель (`/admin`):**
   - 📊 Детальна статистика (користувачі, активні за день, створені стікери, стікерпаки, реферали).
   - 📢 Керування обов'язковими каналами (додавання, увімкнення/вимкнення, видалення).
   - ✉️ Масова розсилка повідомлень усім користувачам із захистом від спам-блокування.

5. **Вірусне зростання та реферальна система:**
   - Персональні реферальні посилання (`t.me/Bot?start=ref_12345`).
   - Підрахунок запрошених користувачів.

## 🛠 Встановлення та запуск

### 1. Створення віртуального середовища
```bash
python -m venv venv
# Windows:
venv\Scripts\activate
# Linux/macOS:
source venv/bin/activate
```

### 2. Встановлення бібліотек
```bash
pip install -r requirements.txt
```

> **Порада щодо rembg:**
> Якщо на сервері немає дискретної відеокарти Nvidia, стандартне встановлення `pip install rembg` автоматично використовує CPU. Для додаткового прискорення можна встановити `pip install onnxruntime`.

### 3. Налаштування `.env`
Відкрийте файл `.env` та вкажіть ваш токен бота:
```env
BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrsTUVwxyz
ADMIN_IDS=[Ваш_Telegram_ID]
```
*(Свій Telegram ID можна дізнатися через бота `@userinfobot`)*

### 4. Запуск бота
```bash
python main.py
```

## 👑 Команди адміністратора

- `/admin` — відкрити інтерактивну панель керування.
- `/stats` — швидкий перегляд метрик та кількості користувачів.
- `/channels` — список активних і неактивних спонсорських каналів.

### Як додати обов'язковий канал через адмінку:
1. Додайте бота адміністратором у канал (з правом запрошувати користувачів).
2. Натисніть **«➕ Додати канал»** в `/admin`.
3. Надішліть дані у форматі:
   ```
   Мій Канал, @channel_username, https://t.me/channel_invite_link, own
   ```
4. Бот автоматично додасть канал у список обов'язкових перевірок для всіх користувачів!
